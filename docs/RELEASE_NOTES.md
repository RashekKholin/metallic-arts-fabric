# The Metallic Arts 1.0.0-rc.2

Minecraft Java **26.1**, Java **25**, Fabric Loader **0.18.4+**, Fabric API **0.145.1+26.1**. Install the ordinary jar on server and clients; the sources jar is for development. Stop the game, back up the whole world/configs and remove the old mod jar before upgrading.

- Requested gameplay fixes: automatic/recovered coin locks, ten-second range retention, connected sources, distance falloff, all-direction blue sight, aluminum/alloy immunity, full-sphere player effects, 64-item stacks, live controls help and faster visible Bendalloy nutrition. See REQUESTED_GAMEPLAY.md for exact limits.
- All rights reserved license selected by the owner, included in ordinary/source jars with explicit gameplay/server-use permission.
- Real NPC storage/tapping with canonical equipment, finite fuel/charge and actual attribute costs; expanded paid standard-metal AI.
- Distinct Koloss/Inquisitor/Kandra NPCs, prepared implants, dependencies, original skins and material-fed forms.
- Rare research camps, finite supplies, researcher profiles, advancement onboarding, a craftable field guide and persistent faction standing.
- Separate finite pure Atium/Nalatium/Malatium interpretations; protected Harmonium/Trellium material transactions and terrain-safe water reactions. Unknown shard-metal abilities remain unresolved.
- Explicit opt-in memory movement and past-vision consent; no raw private journal broadcast.
- Optional real OpenPAC integration, protected loose-force anchors/recoil/time, canonical lease recovery, older-version migration and intentional partial-save crash fixtures.
- Eleven guide pages, 32 metal lessons, rebindable contextual keys, client sensory settings, original item art and narrow-menu/native-rendering checks. Spanish remains partial.
- Expanded CI gates for native server operating systems, Linux software-rendered clients, pinned claim compatibility and save recovery before publishing this immutable prerelease.

The public host-disableable RashekKholin/The17thShard verified-UUID access remains. It grants standard Arts access, no operator privileges or free resources.
