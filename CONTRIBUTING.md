# Contributions

This project currently uses an all-rights-reserved license with explicit play,
server-use and configuration permission. It is not MIT-licensed or open source.

Please report reproducible bugs using the issue templates. Include the exact
Minecraft, Java, Fabric Loader/API and mod versions, other installed mods,
steps to reproduce and a relevant log with credentials and private chat removed.
Test on a backed-up world. Do not upload another person's world or account data.

Discuss code/art contributions before submitting them. Do not include copied
third-party code, book text, logos, official artwork or assets without permission.
Contributor ownership and any future relicensing permission must be resolved
explicitly before accepting outside contributions. A public pull request alone
is not treated as a copyright assignment or unrestricted relicensing permission.
